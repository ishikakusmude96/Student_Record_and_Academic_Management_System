🎓 Student Record & Academic Management System

✨ Smart • Simple • Efficient

A Python-based application designed to simplify student record management and academic data organization.

🚀 Features

- ➕ Add student records
- 📋 Display all students
- 🔍 Search by roll number
- ✏️ Update student information
- 🗑️ Delete student records
- 📊 Calculate average marks
- 🏆 Find the highest scorer
- 🏫 Department-wise student listing
- 👥 Count total students

🛠️ Technologies Used

- Python 
- Jupyter Notebook 📓

🎯 Objective

To demonstrate the practical use of Python programming and collections for efficient student record manage7ment.

▶️ How to Run

1. Open the Jupyter Notebook file.
2. Run the code cell.
3. Select a menu option.
4. Enter the required student information.
